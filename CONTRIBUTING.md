# Contributing

> [!CAUTION]
> **All the code in these repositories was generated by Claude, an AI from Anthropic, and has not been checked by a person.** It may have bugs or not do what it says. Read it before you rely on it, and use it at your own risk.

Thank you for taking an interest. I'm new to GitHub and still learning how it works, so please bear with me. I'll do my best to look at and support every request.

## Reporting a problem or asking for something

Open an issue in the repository it's about. It helps to say:

- what you did, what happened, and what you expected instead;
- your machine and system. These projects are designed and optimised for a Lenovo ThinkPad T14 Gen 3 running [Omarchy](https://omarchy.org) (Arch Linux and Hyprland), so anything different about yours may matter.

## Proposing a change

Pull requests are welcome. To make them easy to look at:

- keep each one to a single change, and say why it's needed;
- run the repository's tests first (its README and `AGENTS.md` say how);
- follow the rules in its `AGENTS.md` (the Rust ones, for example, use no third-party crates).

If you're planning something large, opening an issue first to talk it over can save you work.
